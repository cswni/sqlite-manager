# Product

## Register

product

## Platform

web

## Users

Primary: developers and data people who live in SQLite files daily — local apps, embedded stores, side projects, migrations. They work at a desk with multiple tables open and need density, speed, and trust over onboarding theater.

Secondary: agents and automation via MCP that need the same engine the UI uses.

## Product Purpose

SQLite Manager is a dense desktop IDE for opening, querying, designing, migrating, and exchanging SQLite databases. Success is: open a `.db`, understand the schema, run SQL, edit rows, apply DDL, and ship migrations without leaving the app — and do the same from an MCP client.

## Positioning

The local SQLite studio that feels like a craft tool, not a dashboard — one engine for humans and agents.

## Brand Personality

Precise, dense, calm. Speaks in short labels and monospace data. No hype copy.

## Anti-references

Purple SaaS gradients, glassmorphism panels, hero-metric marketing chrome, cream/parchment “AI tool” surfaces, oversized display fonts in tool chrome.

## Design Principles

- Density serves the task; chrome stays quiet.
- One vocabulary for buttons, grids, and trees across every surface.
- Show schema and data together; never hide structure behind cards.
- The run action is the only loud control.
- Errors are plain and actionable.

## Accessibility & Inclusion

WCAG AA contrast for body and controls. Keyboard paths for SQL run, tree navigation, and grid focus. Honor `prefers-reduced-motion`.
